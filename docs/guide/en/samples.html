Samples

Run the samples in your browser

Every sample application in the repository, built for the web from the same Rust source it ships as a desktop program. Open one and it runs in the page, with nothing to install.

A page is the renderer's WebAssembly module, Skia's and the sample's own, about 40 MB before compression, so the first load takes a moment. They need a browser with WebAssembly garbage collection, which current Chrome, Edge and Firefox have; they are checked in Chromium. The pages come from the newest sample release, so they can be a little behind the repository. The source of each one is under samples/.

Adaptive

These four take the design system of the platform they run on. In a browser that is Fluent.

calculator

Clone coded from the Windows, macOS and Deepin calculators: a dense key grid, a memory register, and a tape beside the keys or in a sheet.

notepad

Clone coded from the iOS and Windows memo apps: multiline editing, several documents, and the list beside the page or in a sheet.

todo

A task list: stable keys, checkboxes, filters as a destination set, and a lazy list over thousands of rows.

chat

Clone coded from Google Gemini: conversations as a destination set, scrollback, and a reply streamed in from a worker thread.

Unified

Each of these names one design system and draws the same way everywhere. All of them rebuild published iOS designs.

minimal

A monochrome component sheet in its reference's own colours: steppers, a segmented control, cards, switches, a gradient and a shadow.

store

A clothing shop: a carousel with page dots, a category strip, a two-up grid, a product page and a bag that adds up.

statistics

Charts drawn with Canvas: a dial and a week of costs, on a tinted page.

selfcare

A mood check-in: a drawn face per feeling, a chip grid, a row of session cards and a week as a line.

podcast

A player with a Canvas waveform, a cover per show, and a full-screen page over the navigation bar.

academic

A drum school: a grid of subject tiles, a stage strip, and open and locked lessons.

social

A meditation app: an illustration on every card, three shelves, and a course page over the navigation bar.
