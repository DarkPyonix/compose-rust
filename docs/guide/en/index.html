Compose-shaped UI in Rust,drawn by Compose.

A Rust API in the shape of Compose, a narrow C ABI with a generated schema, and an ahead-of-time compiled Compose renderer that draws with Compose's own text layout, widgets and platform IME.

Native UI with no webview and no bundled JVM, aiming at one executable per desktop app.

// Planned shape for 1.0.0. Does not compile against 0.0.x.
#[composable]
fn counter() {
    let count = remember(|| mutable_state_of(0));
    Column(Modifier::new().fill_max_width(), || {
        Text(format!("{}", count.get()));
        Button(|| count.set(count.get() + 1), || Text("+1"));
    });
}

One language for the UI, one engine for the pixels

Rust owns your code and your state. Kotlin owns the pixels, the text stack and the input method. Between them sits a narrow C ABI: synchronous, on one thread, with records read where they were written, so a keystroke gets its answer inside the same call.

The authoring API shown here arrives with 1.0.0 on 2026-10-20. The boundary, the schema and the renderers under it ship today in 0.0.1.
