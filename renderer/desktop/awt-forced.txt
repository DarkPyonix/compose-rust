# Default is first read, which runs Toolkit.loadLibraries and loads libawt even with no display;

# be dropped until the fork stops creating a Cursor there, which is
# thisisthepy/compose-multiplatform-core-extended#15. scripts/tests/no-awt-on-shipped-path.test.sh
# fails for a new name that is not listed, so this file can only shrink.
